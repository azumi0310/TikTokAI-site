CURRENT FEATURES

現在できること

利用対象は、ユーザー本人が所有する動画、または編集・利用する権限を持つ動画です。AIの分析や提案は補助として利用し、内容は人間が確認します。

01

動画分析と候補選択

映像を分析し、ハイライト候補の選択を補助します。分析結果には不明点や誤認が含まれる場合があります。

02

縦型動画と編集補助

カットの組み合わせや縦型へのリフレーム、字幕・タイトルなどの編集を補助します。

03

投稿パッケージの準備

投稿用のcaption（キャプション）、hashtag（ハッシュタグ）、要約とメタデータを準備し、投稿前に確認できる形式で保存します。

このWebサイトはツールの説明ページです。動画のアップロード、ログイン、編集、投稿をこのページ上で実行する機能はありません。

PLANNED INTEGRATION

TikTok連携について

TikTok OAuth / Login Kitによる認証と、TikTok Content Posting APIを利用した投稿機能を開発中です。現時点では、TikTokアカウントへの接続やAPI経由の投稿は行っていません。

連携を実装する際は、ユーザー本人の認証とアクセス許可が必要です。投稿する動画・本文・公開設定を本人が確認し、明示的に同意した後に投稿処理を行う設計を予定しています。

利用可能な連携機能は、TikTokの審査、付与される権限、APIの条件によって異なります。審査通過や投稿機能の提供時期を保証するものではありません。

開発と運営

TikTokAIは、個人開発者が自身の動画編集・投稿準備のために開発している独立したツールです。現在、一般向けの利用登録や商用サービスの提供は行っていません。

TikTokAIはTikTokまたはByteDanceが提供・承認・運営するサービスではなく、両社との提携関係を示すものでもありません。TikTok等の名称は、連携先を説明するために使用しています。

お問い合わせ・削除に関する窓口
